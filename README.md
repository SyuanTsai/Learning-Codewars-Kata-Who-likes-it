# Who likes it?

A small .NET solution and unit-test project for the Codewars
[Who likes it? kata](https://www.codewars.com/kata/5266876b8f4bf2da9b000362).

The original kata statement and hidden tests are not reproduced here. The
implementation is an incomplete study exercise; it should not be read as a
claim of production completeness.
